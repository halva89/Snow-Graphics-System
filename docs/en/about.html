About

Snow Graphics System (SGS) is a free open-source graphics engine. The project was created for learning low-level graphics and developing interactive scenes.

Developer

Author: Halva (Maks Babiychuk).
The project has been running since 2026.

Fact of the day

The engine name comes from the first letters of Snow Graphics System. Versions are named after elements of the periodic table.
