Architecture

SGS is built on a modular architecture. Each component handles its own task.

Languages

  • Rust — main language.
  • GLSL — shaders.

Libraries

  • winit — window creation.
  • ash — Vulkan wrapper.
  • raw-window-handle — window management.

Supported devices

  • Windows 10/11 (64-bit).
  • GPUs with Vulkan 1.0 support.
