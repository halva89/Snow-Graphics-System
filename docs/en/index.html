Snow Graphics System

Snow Graphics System is a graphics engine written in Rust with Vulkan. Created for learning graphics, experimenting, and developing small 3D projects.

Latest version

Lithium V2 (Red Wolf) — Alpha 3.1.
Supports animation, camera, .sgss parser, and dynamic viewport.

Quick start

  1. Download the latest release here.
  2. Extract the archive.
  3. Run snow_graphics.exe.

Or build from source: 

git clone https://github.com/halva89/Snow-Graphics-System.git
cd Snow-Graphics-System
cargo run --release
