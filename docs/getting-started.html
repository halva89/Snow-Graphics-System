Начало работы

Установка

  1. Скачай последний релиз с GitHub.
  2. Распакуй архив.
  3. Запусти snow_graphics.exe.

Открытие

По умолчанию движок загружает assets/level1.sgss. 

cargo run -- assets/level1.sgss

Редактирование

Файлы .sgss — это текстовые файлы. Открой любой в блокноте и изменяй координаты.
