main.frame

main.frame (MF) — бесплатный open-source графический движок на Rust с использованием Vulkan API. Спроектирован для интерактивных 2D/3D-сцен, описываемых в собственном текстовом формате .mff. Разрабатывается автором Halva (Maks Babiychuk) с июля 2026 года под лицензией GNU GPL v3 (copyleft).

// Beryllium: добавлено управление камерой
pub struct Engine {
    scene: Scene,
    renderer: Renderer,
    window: CustomWindow,
    animator: Animator,
    is_running: bool,
    camera_pos: Vec3,
    camera_target: Vec3,
}

// В цикле: обработка WASD + Q/E
let speed = 3.0 * self.window.time.delta();
let forward = (self.camera_target - self.camera_pos).normalize();
let right = forward.cross(&Vec3::new(0.0, 0.0, 1.0)).normalize();
// W/S — вперёд/назад; A/D — влево/вправо; Q/E — вверх/вниз
self.renderer.set_camera(self.camera_pos, self.camera_target);

Последовательность инициализации:

1. Entry::load()                    — загрузка Vulkan-библиотеки
2. Instance::create()               — создание экземпляра с расширениями
3. Surface::create()                  — поверхность окна (GLFW → ash)
4. PhysicalDevice::select()          — выбор GPU (дискретный / интегрированный)
5. Device::create()                  — логическое устройство
6. Swapchain::create()               — цепь смены кадров
7. ImageViews::create()              — представления изображений
8. RenderPass::create()              — проход рендеринга + depth attachment
9. DescriptorSetLayout+Pool+Set      — дескрипторы: scene UBO + overlay UBO
10. PipelineLayout + Pipeline         — графический конвейер
11. Framebuffers                      — кадровые буферы (color + depth)
12. CommandPool + CommandBuffers     — командные буферы
13. VertexBuffer + IndexBuffer       — вершинный и индексный буферы
14. EdgeBuffer (wireframe)           — рёбра для каркасного режима
15. UniformBuffer × 2                — сцена и оверлей
16. Semaphores + Fence               — синхронизация

Рендер-цикл (vulkan.rs)

1. fence.wait → acquire_next_image (при OUT_OF_DATE → rebuild_swapchain)
2. Сборка всех вершин и индексов из объектов сцены
3. Проход по граням: генерация рёбер для wireframe (кроме граничных)
4. Обновление Uniform-буфера сцены (projection/view/model)
5. Обновление Uniform-буфера оверлея (ortho, z=0)
6. Пересоздание буферов при изменении размера
7. Запись command buffer:
   a. bind descriptor scene → cmd_draw_indexed(сцена)
   b. если wireframe: bind edge-буфер → draw рёбер (чёрные линии)
   c. bind descriptor overlay → draw панели + кнопок UI (поверх, z=0, LESS_OR_EQUAL)
8. queue_submit → queue_present
9. Очистка цвета: [0.1, 0.2, 0.3, 1.0]

Парсер — построчное чтение:

1. Чтение window / title
2. Для каждой строки:
   - triangle → парсинг 3 вершин
   - square   → парсинг позиции + размера
   - circle   → парсинг центра + радиуса + сегментов
   - cube     → парсинг размера (3D)
   - sphere   → парсинг радиуса + секторов (3D)
   - animate  → парсинг keyframe (время + позиция + цвет)
3. Возврат (SceneSettings, Vec<SceneObject>)

Формат MFF

.mff — main.frame Format: собственный текстовый формат описания сцен main.frame. Человекочитаемый, не требует компиляции, редактируется в любом текстовом редакторе. Парсер (src/scene_parser/) читает файл построчно: строки window/title уходят в настройки окна, директивы position/physics запоминаются как «ожидающие» и применяются к следующему объекту, а фигуры (triangle, square, circle, cube, sphere, mesh, animate) превращаются в SceneObject.

Полный синтаксис (BNF)


scene        := settings? object*
settings     := ( window | title | render_mode | camera
                  | decorated | resizable | wireframe )+
window       := "window" NUM NUM
title        := "title" STR
render_mode  := "render_mode" ( "light" | "heavy" )
camera       := "camera" BOOL
decorated    := "decorated" BOOL
resizable    := "resizable" BOOL
wireframe    := "wireframe" BOOL
object       := prefix? shape | "animate" shape
prefix       := ( "position" NUM NUM NUM | "physics:" phys ','* )*
shape        := "triangle" VEC2 VEC2 VEC2 COLOR
              | "square" NUM NUM NUM COLOR
              | "circle" NUM NUM NUM NUM COLOR
              | "cube" NUM COLOR
              | "sphere" NUM NUM COLOR
              | "mesh" STR COLOR?
animate      := "animate" ( "triangle" | "square" | "circle"
                            | "cube" | "sphere" )
                keyframe+ ("}")?
keyframe     := "keyframe" NUM ( pos/color | raw )+
phys         := ( "m"|"mass" ) "=" NUM | ( "f"|"restitution"|"elasticity" ) "=" NUM
              | ( "p"|"density" ) "=" NUM
BOOL         := "true" | "false" | "1" | "0" | "on" | "off"
COLOR        := NUM NUM NUM
VEC2         := NUM NUM

Экосистема MF

MF (main.frame)

Ядро движка. Отвечает за рендеринг, логику, физику и анимацию. Всё, что описано выше — это MF.

MFF (main.frame Format)

Формат сцен .mff — текстовый файл, описывающий объекты, анимации и настройки окна. Полный синтаксис описан выше.

MFF Editor (планируется)

Визуальный редактор для создания .mff-файлов. Позволит рисовать сцены, расставлять объекты и экспортировать в .mff без ручного написания кода. Статус: не начат.
