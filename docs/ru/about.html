О программе

Snow Graphics System (SGS) — это бесплатный графический движок с открытым исходным кодом. Проект создан для изучения низкоуровневой графики и разработки интерактивных сцен.

О разработчике

Автор: Halva (Maks Babiychuk).
Проект ведётся с 2026 года.

Факт дня

Название движка происходит от первых букв слов Snow Graphics System. Версии называют в честь элементов таблицы Менделеева.
