Архитектура

SGS построен на модульной архитектуре. Каждый компонент отвечает за свою задачу.

Используемые языки

  • Rust — основной язык.
  • GLSL — шейдеры.

Библиотеки

  • winit — создание окна.
  • ash — обёртка над Vulkan.
  • raw-window-handle — работа с окном.

Поддерживающиеся устройства

  • Windows 10/11 (64-bit).
  • Видеокарты с поддержкой Vulkan 1.0.
