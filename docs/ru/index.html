Snow Graphics System

Snow Graphics System — графический движок на Rust с использованием Vulkan. Создан для изучения графики, экспериментов и разработки небольших 3D-проектов.

Lithium V2 (Red Wolf) — Alpha 3.1.
Поддерживает анимацию, камеру, парсер .sgss и динамический вьюпорт.
