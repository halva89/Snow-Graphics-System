main.frame - релизный бинарник (Windows)

Запуск:
  main_frame.exe <сцена.mff>
  main_frame.exe thermal.mff     # демо: тепловизор
  main_frame.exe frame.mff       # демо: появление бордовой рамки

Примечание: шейдеры читаются из подпапки shaders/ относительно рабочей
папки. Запускайте бинарник из его собственной папки (двойной клик или
cd в папку release и ./main_frame.exe).

Требования: драйвер с поддержкой Vulkan 1.0+.
Сцены .mff: текстовый формат, объекты, анимации, физика, температура (temp).
