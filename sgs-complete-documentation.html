Snow Graphics System

Snow Graphics System (SGS) — бесплатный open-source графический движок на Rust с использованием Vulkan API. Спроектирован для интерактивных 2D/3D-сцен, описываемых в собственном текстовом формате .sgss. Разрабатывается автором Halva (Maks Babiychuk) с июля 2026 года под лицензией GNU GPL v3 (copyleft).

Ключевые изменения в коде:

Engine теперь с камерой:

// Beryllium: добавлено управление камерой
pub struct Engine {
    scene: Scene,
    renderer: Renderer,
    window: CustomWindow,
    animator: Animator,
    is_running: bool,
    camera_pos: Vec3,
    camera_target: Vec3,
}

// В цикле: обработка WASD + Q/E
let speed = 3.0 * self.window.time.delta();
let forward = (self.camera_target - self.camera_pos).normalize();
let right = forward.cross(&Vec3::new(0.0, 0.0, 1.0)).normalize();
// W/S — вперёд/назад; A/D — влево/вправо; Q/E — вверх/вниз
self.renderer.set_camera(self.camera_pos, self.camera_target);

Vulkan: добавлен Uniform-буфер с дескрипторами:

// Новый Uniforms struct

fn main() {

Архитектура

SGS построен на модульной архитектуре. Каждый компонент отвечает за свою задачу. Ниже — детальный разбор каждого модуля с кодом ключевых функций.

Модуль core — ядро движка

Файлы: engine.rs · scene.rs · object.rs · transform.rs

Engine — главный цикл

pub struct Engine {
    scene: Scene,         // Контейнер объектов
    renderer: Renderer,   // Обёртка Vulkan
    window: CustomWindow, // Окно + ввод
    animator: Animator,   // Проигрыватель анимаций
    is_running: bool,
    camera_pos: Vec3,     // Позиция камеры
    camera_target: Vec3,  // Цель камеры
}

// Основной цикл:
loop {
    self.window.poll_events();
    self.renderer.render(&self.scene);  // один вызов на кадр
}

Последовательность инициализации:

1. Entry::load()                    — загрузка Vulkan-библиотеки
2. Instance::create()               — создание экземпляра с расширениями
3. Surface::create()                  — поверхность окна (winit → ash)
4. PhysicalDevice::select()          — выбор GPU (дискретный / интегрированный)
5. Device::create()                  — логическое устройство
6. Swapchain::create()               — цепь смены кадров
7. ImageViews::create()              — представления изображений
8. RenderPass::create()              — проход рендеринга
9. DescriptorSetLayout+Pool+Set     — дескрипторы для Uniform-буфера
10. PipelineLayout + Pipeline         — графический конвейер
11. Framebuffers                      — кадровые буферы
12. CommandPool + CommandBuffers     — командные буферы
13. VertexBuffer + IndexBuffer       — вершинный и индексный буферы
14. UniformBuffer                    — uniform-буфер
15. Semaphores + Fence               — синхронизация

Uniform-буфер (uniform.rs)

#[repr(C)]
pub struct Uniforms {
    pub projection: Mat4,   // матрица проекции

Рендер-цикл (vulkan.rs)

1. begin_frame():  fence.wait → acquire_next_image → queue_submit
2. Сборка всех вершин и индексов из объектов сцены
3. Обновление Uniform-буфера (projection/view/model)
4. Пересоздание вершинного/индексного буфера при изменении размера
5. Параллельное копирование данных: rayon::join(vertex, index)
6. Параллельная запись command buffers: par_iter().for_each()
7. end_frame(): queue_present
8. Очистка цвета: [0.1, 0.2, 0.8, 1.0] — синий фон

pub struct SceneSettings {
    pub width: u32,
    pub height: u32,
    pub title: String,
}

pub enum SceneObject {
    Static(RawMesh),       // triangle, square, circle, cube, sphere
    Animated(AnimatedMesh), // animate + keyframes

pub struct RawMesh {

Парсер — построчное чтение:

1. Чтение window / title
2. Для каждой строки:
   - triangle → парсинг 3 вершин
   - square   → парсинг позиции + размера
   - circle   → парсинг центра + радиуса + сегментов
   - cube     → парсинг размера (3D)
   - sphere   → парсинг радиуса + секторов (3D)
   - animate  → парсинг keyframe (время + позиция + цвет)
3. Возврат (SceneSettings, Vec<SceneObject>)

Формат .SGSS

.sgss — собственный текстовый формат описания сцен Snow Graphics System. Человекочитаемый, не требует компиляции, редактируется в любом текстовом редакторе.

Синтаксис

window <width> <height>                # Настройки окна
title "<заголовок>"                     # Заголовок окна

# 2D-примитивы:
triangle                                    # Треугольник
<x1> <y1>
<x2> <y2>
<x3> <y3>
<r> <g> <b>

square                                      # Квадрат
<x> <y> <size>
<r> <g> <b>

circle                                      # Круг
<cx> <cy> <radius> <segments>
<r> <g> <b>

# 3D-примитивы:
cube                                        # Куб
<size>
<r> <g> <b>

sphere                                      # Сфера
<radius>
<sectors>
<r> <g> <b>

# Анимация:
animate <shape>                             # Анимированный объект
    keyframe <time>                         # Ключевой кадр
        pos <x> <y> <z>
        color <r> <g> <b>

Экосистема SGS

SGS (Snow Graphics System)

Ядро движка. Отвечает за рендеринг, логику, физику и анимацию. Всё, что описано выше — это SGS.

SGSS (Snow Graphics Scene System)

Формат сцен .sgss — текстовый файл, описывающий объекты, анимации и настройки окна. Полный синтаксис описан выше.

SGSS Editor (планируется)

Визуальный редактор для создания .sgss-файлов. Позволит рисовать сцены, расставлять объекты и экспортировать в .sgss без ручного написания кода. Статус: не начат.
